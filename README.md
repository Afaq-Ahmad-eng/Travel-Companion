# Smart Travel Companion (STM) - Tourism Assistant for KPK
  STM (Smart Travel Companion) is a travel assistant designed for tourists exploring Khyber Pakhtunkhwa (KPK), Pakistan. 
  It helps users plan their trips, discover attractions, and access travel information efficiently. 
  The project aims to enhance tourism experiences by providing a smart, interactive, and user-friendly platform for travelers.
## Features
- User registration and authentication for personalized travel plans.
- Explore tourist destinations in KPK with detailed descriptions and images.
- Interactive maps to guide users to attractions.
- Daily trip planner and suggested itineraries.
- Backend powered by Node.js, Express with a MySQL + Prisma database.

  ## Technologies Used
- Frontend: React.js, HTML, CSS, bootstrap, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL with Prisma ORM
- Authentication: JWT tokens with cookie-based sessions
- Others: SweetAlert2 for interactive alerts, Google Maps API

## How It Works
1. User signs up and logs into the system.
2. User searches for destinations or plans a trip.
3. Backend fetches relevant travel data and stores user preferences.
4. Users get personalized recommendations and interactive maps.
5. Admin can manage destinations and monitor user activity.
